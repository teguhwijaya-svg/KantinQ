## 📌 About KantinQ

**KantinQ** adalah aplikasi kantin digital yang bertujuan untuk
mempermudah aktivitas jual beli makanan dan minuman di lingkungan
kantin.

Dengan memanfaatkan teknologi digital, KantinQ menghadirkan
pengalaman pemesanan yang lebih modern, mudah, dan efisien bagi
pelanggan maupun pengelola kantin.

## ✨ Features

- 🛍️ **Digital Menu**  
  Menampilkan berbagai pilihan makanan dan minuman.

- 🛒 **Online Ordering**  
  Memungkinkan pelanggan melakukan pemesanan secara online.

- 💰 **Payment System**  
  Mempermudah proses transaksi pembayaran.

- 📋 **Order Management**  
  Mengelola dan memantau pesanan pelanggan.

- 👤 **User Management**  
  Mengelola informasi dan akun pengguna.

- 📊 **Admin Dashboard**  
  Membantu pengelola kantin mengelola menu dan transaksi.

## 🎯 Project Goals

KantinQ dikembangkan dengan beberapa tujuan:

1. Mempermudah proses pemesanan makanan dan minuman.
2. Meningkatkan efisiensi pelayanan kantin.
3. Mengurangi antrean saat melakukan pemesanan.
4. Mendukung digitalisasi sistem kantin.
5. Memberikan pengalaman transaksi yang lebih praktis.

## 🚀 Installation

Ikuti langkah berikut untuk menjalankan project KantinQ:

**1. Clone Repository**

```bash
git clone https://github.com/USERNAME/KantinQ.git
```

**2. Masuk ke Direktori Project**

```bash
cd KantinQ
```

**3. Install Dependencies**

```bash
npm install
```

**4. Jalankan Aplikasi**

```bash
npm run dev
```
